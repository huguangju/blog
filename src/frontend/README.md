# 前端技术

汇集前端开发的各个方面，从源码学习到工程化实践，从性能优化到基础知识巩固。

## 📚 内容分类

### [源码学习](source-code/)

深入分析主流前端框架和优秀工具库的源码实现

- Vue.js 源码解析
- React 源码分析  
- 工具库源码学习

### [前端工程化](engineering/)

现代前端开发的工程化实践和工具链

- 构建工具配置与优化
- 开发环境搭建
- 部署策略与 CI/CD

### [性能优化](performance/)

前端性能优化的理论与实践

- Web Vitals 核心指标
- 优化技巧与最佳实践
- 性能监控与分析

### [基础知识](fundamentals/)

前端开发的核心基础知识

- JavaScript 深入理解
- CSS 进阶技巧
- HTML 语义化
- 浏览器工作原理

## 🎯 学习路径

1. **基础巩固**：从 fundamentals 开始，夯实基础
2. **工程实践**：学习 engineering 中的工程化知识
3. **性能提升**：掌握 performance 优化技巧
4. **源码探索**：深入 source-code 理解原理

## 📖 推荐阅读顺序

- 新手：基础知识 → 工程化 → 性能优化 → 源码学习
- 进阶：源码学习 → 性能优化 → 工程化实践
- 专家：关注最新技术趋势和深度源码分析

# 算法与数据结构

算法是程序的灵魂，数据结构是程序的骨架。这里记录算法学习。

## 📊 内容分类

### [数据结构](data-structures/)

常用数据结构的实现与应用

- 线性结构：数组、链表、栈、队列
- 树形结构：二叉树、平衡树、堆
- 图结构：图的表示与遍历
- 哈希表：散列函数与冲突处理

### [算法实现](algorithms/)

经典算法的 JavaScript 实现

- 排序算法：冒泡、快排、归并等
- 搜索算法：二分查找、深度优先、广度优先
- 动态规划：背包问题、最长子序列等
- 贪心算法：活动选择、最小生成树等

### [LeetCode 题解](leetcode/)

力扣刷题记录与解题思路

- 按难度分类：简单、中等、困难
- 按类型分类：数组、字符串、树、图等
- 解题模板与技巧总结

## 🎯 学习建议

1. **理论与实践结合**：理解原理，动手实现
2. **循序渐进**：从简单到复杂，逐步提升
3. **多做练习**：通过 LeetCode 巩固知识
4. **总结归纳**：整理解题模板和套路
